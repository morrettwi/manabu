Fitur Lengkap

Semua Yang Anda Perlukan untuk Menguasai Bahasa Jepang

Dari huruf asas hingga persediaan JLPT, Manabu merangkumi setiap aspek pembelajaran bahasa Jepang dalam satu aplikasi.

あ

Sistem Kana Interaktif

Belajar semua 46 huruf Hiragana dan Katakana dengan animasi susunan tulisan (stroke order), sebutan audio native, dan latihan menulis di layar.

Stroke OrderAudio NativeLatihan Menulis

Pembelajaran Kanji JLPT

Telah 2,136 kanji Jouyou dengan makna, bacaan on'yomi dan kun'yomi, contoh kata, dan susunan mengikut JLPT N5 hingga N1. Setiap kanji mempunyai animasi stroke order.

2,136 KanjiJLPT N5-N1On/Kun'yomi
🔄

Sistem Pengulangan Berjarak (SRS)

Algoritma SRS yang cerdas mengulang kartu pada waktu yang optimal untuk mencegah lupa. Berdasarkan formula SM-2 yang terbukti efektif untuk hafalan jangka panjang.

Algoritma SM-2AdaptiveOffline
📖

Kosakata

Ribuan kata dengan terjemahan, contoh ayat, dan sebutan audio. Dikategorikan mengikut tema: sapaan, makanan, keluarga, pekerjaan, dan banyak lagi.

10,000+ KataContoh AyatAudio
📝

Tata Bahasa Terstruktur

Pelajaran tata bahasa yang tersusun dari asas hingga lanjutan, setiap pola dengan penjelasan, contoh, dan latihan. Ikut susunan JLPT untuk pembelajaran terstruktur.

200+ PolaLatihanPenjelasan
🎧

Latihan Listening

Latihan pendengaran dengan audio native speaker. Dari kata tunggal hingga perbualan penuh. Dukungan untuk berbagai kecepatan untuk sesuai dengan tahap anda.

Audio NativeMulti-speedDictation
🏆

Gamifikasi

Sistem XP, level, rentetan harian (streak), dan lencana pencapaian untuk memastikan motivasi belajar. Papan skor mingguan untuk bersaing dengan diri sendiri.

XP & LevelStreaksBadges
📱

Widget & Notifikasi

Widget layar utama Android untuk memantau progres dan akses cepat ke kartu SRS. Notifikasi cerdas untuk mengingatkan pengulangan harian pada waktu yang tepat.

Home WidgetSmart NotifQuick Action

Teknologi 100% Gratis

Dibangun dengan Alat Sumber Terbuka

Setiap teknologi yang digunakan dalam pembangunan Manabu adalah gratis dan sumber terbuka. Tiada yuran pelesenan, tiada langganan berbayar.

Gratis

React Native + Expo

Framework JavaScript untuk membangun aplikasi Android (dan iOS) native dengan satu codebase. Expo menyediakan build awan gratis.

Gratis

Android Studio

IDE resmi Android dengan emulator gratis untuk uji aplikasi tanpa peranti fizikal. Termasuk SDK lengkap.

Gratis

Firebase (Spark Plan)

Pengelolaan pengguna, cloud sync, dan storage audio — semua dalam tier gratis untuk hingga 50,000 pengguna aktif.

Gratis

SQLite / WatermelonDB

Database local untuk simpan data kana, kanji, dan progres pengguna. Berfungsi sepenuhnya offline tanpa biaya server.

Gratis

Android TTS Engine

Text-to-Speech native Android untuk sebutan bahasa Jepang. Tiada biaya API berbayar, gunakan enjin TTS sistem.

Gratis

KANJIDIC2 + JMDict

Database resmi kanji dan kata Jepang oleh EDICT/Jisho.org. Lesen terbuka, gratis untuk digunakan komersial dan bukan.

Gratis

GitHub + GitHub Actions

Host kod sumber dengan repositori gratis unlimited untuk umum. CI/CD dengan GitHub Actions untuk build APK secara otomatis.

Gratis

VS Code + ESLint

Editor kod gratis dengan plugin lengkap untuk React Native. Linting otomatis untuk kualitas kod yang konsisten.

Rencana Pengembangan

Roadmap dari Konsep ke Lancar

Fase pembangunan Manabu dari prototaip hingga aplikasi penuh di Google Play Store — semua gratis.

✓
Selesai

Fase 1: Penelitian & Konsep

Definisi keperluan, penyelidikan sumber data terbuka, dan desain konsep aplikasi.

  • Kajian aplikasi pembelajaran bahasa sedia ada
  • Pemilihan teknologi (React Native + Expo)
  • Pengumpulan data: KANJIDIC2, JMDict, Tatoeba
  • Desain UX/UI dengan Material Design 3
⚡
Sedang Berjalan

Fase 2: Prototipe Interaktif

Membangunkan prototipe fungsional yang anda lihat di atas untuk mengesahkan konsep dan UX.

  • Skrin Beranda dengan dashboard
  • Modul Kana (Hiragana & Katakana) dengan audio
  • Engine kartu SRS dengan algoritma SM-2
  • Modul kuiz dengan pilihan berganda
  • Papan skor, XP, dan pencapaian
3
Akan Datang

Fase 3: Pembangunan Aplikasi Penuh

Menukar prototaip ke aplikasi Android native dengan semua fitur lengkap.

  • Setup projek React Native + Expo
  • Implementasi database SQLite dengan 2,136 kanji
  • Animasi stroke order untuk kana & kanji
  • Integrasi Android TTS untuk sebutan
  • Widget layar utama & notifikasi pintar
  • Ujian dengan emulator Android dan peranti nyata
4
Akan Datang

Fase 4: Beta & Ujian Pengguna

Ujian dengan pengguna nyata untuk mendapatkan umpan balik dan memperbaiki kualitas.

  • Distribusi beta melalui Expo atau APK langsung
  • Pengumpulan umpan balik pengguna
  • Debugging dan optimasi prestasi
  • Tambah fitur berdasarkan umpan balik
5
Akan Datang

Fase 5: Rilis di Google Play

Publikasi aplikasi di Google Play Store secara gratis.

  • Daftar akun Google Play Developer (biaya sekali $25 USD)
  • Siapkan daftar Play Store (gambar, video, deskripsi)
  • Submit APK/AAB untuk peninjauan
  • Rilis secara umum gratis
  • Pembaruan berkelanjutan berdasarkan umpan balik
